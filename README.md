# Капитан на удалёнке — прототип 0.1

Научно-фантастическая игра для телефона: вы капитан исследовательского корабля «Странник». Корабль «летит сам», а вы отвечаете на события, пока не истечёт таймер. Если не успеете, решение примет старпом — и оно не всегда будет удачным.

Это первый играбельный прототип: мобильное веб-приложение (PWA). Его можно открыть в браузере телефона и добавить на рабочий стол.

## Как запустить

Игру нельзя просто открыть как файл `index.html` — нужен локальный веб-сервер (так работают уведомления и установка на домашний экран).

На компьютере с Windows, в папке проекта:

```bat
cd app
python -m http.server 8080
```

Если Python не установлен, подойдёт любой другой сервер, например:

```bat
npx --yes serve -l 8080 app
```

Дальше в браузере компьютера откройте `http://localhost:8080`.

Чтобы играть на телефоне (OnePlus и любой другой Android) в той же Wi‑Fi сети:

1. Узнайте IP компьютера (в `cmd`: `ipconfig`, строка «IPv4»).
2. На телефоне откройте `http://IP-КОМПЬЮТЕРА:8080`, например `http://192.168.1.15:8080`.
3. В Chrome: меню → «Добавить на главный экран» / «Установить приложение».

Игра запоминает прогресс в браузере телефона (`localStorage`).

## Как играть

1. Примите входящий приказ штаба.
2. На **Пульте** смотрите сводку и нажмите «Продолжить полёт» — придёт событие.
3. На экране **Событие** прочитайте советы офицеров (они часто спорят), выберите вариант или напишите свой.
4. Код бросает d20 с модификатором офицера и систем корабля. Итог: успех, частичный успех или провал.
5. Если таймер истечёт, решение принимает старпом Елена Волкова.
6. Остальные разделы: **Миссия**, **Судовой журнал**, **Офицеры** (карточка + чат), **Корабль**, **Настройки**.

По умолчанию на решение даётся 3 минуты (для проверки, не часы). В настройках можно поставить 30 секунд, 10 минут или своё значение.

## Режим ИИ и офлайн

В **Настройках** можно указать:

- базовый URL OpenAI-совместимого API (официальный OpenAI, Open WebUI, Ollama и т.п.);
- ключ;
- имя модели.

Модель придумывает события, советы, тексты последствий и ответы офицеров в чате. Броски кубика и правила считает программа, не модель. Если модель не ответила, игра сама переходит на встроенный набор (10 готовых событий и заготовленные реплики офицеров). Без ключа прототип полностью играбелен офлайн.

Ключ хранится только на устройстве, никуда не отправляется, кроме указанного вами адреса API.

## Что уже работает

- Все экраны из требований, переход в один тап, кнопка «назад».
- Состояние корабля, шесть старших офицеров, основной приказ и цели.
- Случайные события, таймер, свой текст, старпом по истечении времени.
- Сохранение и загрузка, сброс кампании (ключ API при этом остаётся).
- Системные уведомления браузера, пока вкладка или установленное приложение открыты.
- Офлайн-кэш приложения через service worker.

## Что дальше

- Настоящие фоновые пуш-уведомления, когда телефон заблокирован, **нужен сервер** (подписка Web Push и планировщик событий). В браузере без сервера этого сделать нельзя.
- Позже прототип можно обернуть в Android-приложение (Trusted Web Activity / Capacitor).
- Баланс таймеров и частоты событий, конец кампании и «смерть» корабля — пока сделаны упрощённо.
- Отдельный бот под разработку игры, если решите его завести.
